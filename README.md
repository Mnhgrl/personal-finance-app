# Миний хувийн санхүү

Python + Streamlit + SQLite ашигласан, өөрийн компьютер дээр ажиллах санхүүгийн апп.
Excel хуулга импортлох, сарын төсөв ба гүйцэтгэл, урт хугацааны зорилго гэсэн даалгаврын
үндсэн 3 функцийг хэрэгжүүлсэн. GitHub repository болон collaborator-ыг эзэмшигч өөрөө тохируулна.

## Файлууд

- finance.py — бүх аппын бүтэн код, нэмэлт өөрийн Python модуль шаардахгүй.
- requirements.txt — Python сангууд.
- test_finance.py — 11 автомат тест.
- start_finance.bat — Windows дээр апп асаах.
- .gitignore — өгөгдлийн сан, хувийн Excel, нууц тохиргоог git-д оруулахгүй.
- SETUP_MN.md — Windows, GitHub болон collaborator-ийн дэлгэрэнгүй алхам.

## Ажиллуулах

Python 3.10+ шаардлагатай. Терминалыг кодын хавтаст нээгээд:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run finance.py
```

Аппын өгөгдөл finance.py-тай ижил хавтасны finance_account.db файлд хадгалагдана.
Хуучин энэ нэртэй сан байвал шинэ хүснэгтүүдийг нэмж, гүйлгээнүүдийг хадгална.
Өмнөх finance.db нь тусдаа хэвээр. Нөөцлөхдөө аппыг зогсоож .db файлаа хуулна.

## 1. Банкны хуулга импорт

- Хавсаргаж шалгасан account-statement (9 багана) болон ST (29/30 багана) форматууд.
- .xlsx болон .xls сонгож импортлоно.
- Дараагийн хугацааны хуулга өмнөх мэдээлэл дээр нэмэгдэнэ.
- Файлын SHA256 болон гүйлгээний тогтвортой ID-аар давхардлыг алгасана.
- Мөр бүрийн үлдэгдэл, нийт орлого/зарлага, эцсийн үлдэгдлийг шалгана.
- Алдаатай файл бүхэлдээ хадгалагдахгүй.
- Гараар зассан ангилал, байгууллагын дүрэм давуу эрхтэй.

Нэг дансны ST болон account экспортуудын давхцах хугацааг шууд нийлүүлэхгүй.
Эдгээрийн нэг секунд дэх гүйлгээний дараалал, тайлбар, үлдэгдэл өөрчлөгдөж болдог.
Шинэ аппдаа account форматаа тогтмол ашиглахыг зөвлөж байна. Дурын банкны
Excel эсвэл байнга өөрчлөгдөх экспортуудыг бүгдийг дэмждэг гэсэн баталгаа биш.

## 2. Төсөв ба гүйцэтгэл

- Анх нээхэд дараагийн сар сонгогдоно; YYYY-MM утгаар бусад сарыг сонгоно.
- Орлого, зарлагыг ангилал тус бүрээр төлөвлөн хадгална.
- Ижил сар/ангилал/төрлөөр дахин хадгалбал төлөвлөсөн дүн шинэчлэгдэнэ.
- Өмнөх сарын төсвийг шинэ сар руу хуулна (шинэ сарын байгаа мөрийг дарж бичихгүй).
- Хуулгын бодит гүйцэтгэл, төсөв, зөрүүг хүснэгт ба графикаар харуулна.
- Төсөв бүх дансны нийлбэр; dashboard-ийн дансны шүүлтүүрээс хамаарахгүй.
- Хуулга ороогүй сар гүйцэтгэл 0; энэ нь бодит зарлага байгаагүйг батлахгүй.
- Орлогын зөрүү = төлөвлөгөө − бодит орлого; зарлагын зөрүү = төсөв − бодит зарлага.
- Зорилгын төлбөрүүдийг оруулаад орлого хүрэхгүй үед дутуу дүнг харуулна.

## 3. Урт хугацааны зорилго ба хосолмол санхүүжилт

Олон зорилго үүсгэж, нэр, үнэ, эхний хуримтлал, нэмэлт эх үүсвэр,
зээл, жилийн хүү, зээлийн хугацаа, эхлэх ба хүрэх сарыг оруулна.

Шинээр хуримтлуулах дүн = үнэ − эхний хуримтлал − нэмэлт эх үүсвэр − зээл.
Сарын хуримтлал = шинээр хуримтлуулах дүн / саруудын тоо.
Эхлэх ба хүрэх сарыг хоёуланг нь хамруулна. Бутархайн үлдэгдлийг сүүлийн сард засна.

Зээлийн сарын төлбөр аннуитет аргаар: P*r/(1-(1+r)^(-n)).
r = жилийн нэрлэсэн хүү / 12 / 100. Хүү 0 бол P/n.
Зээл хүрэх сард олгогдож, дараагийн сараас төлөгдөх төсөөлөлтэй.
Сүүлийн зээлийн төлбөрт үлдэгдлийн нарийвчлалыг засна.

- Зорилгын сарын хуримтлал, зээлийн төлбөр сарын төсөвт шууд орно.
- Хуримтлал руу шилжүүлсэн/зээл төлсөн бодит гүйлгээг зорилгод холбоно.
- Холболтын дүнг ердийн зарлагаас хасч зорилгын гүйцэтгэлд нэг удаа тооцно.
- Нэг гүйлгээг хэд хэдэн зорилгод хувааж болно, нийт дүнгээс хэтрүүлэхгүй.
- Ижил гүйлгээ/зорилго/төрлийг дахин хадгалах нь шинэ нэмэлт биш, дүнгийн шинэчлэлт.
- Холболтыг салгаж засаж болно. Зорилгын нөхцөлийг засаж, төсөвт оруулахыг унтрааж болно.
- Явцад зөвхөн эхний болон бодит холбосон хуримтлал орно; ирээдүйн зээл/бэлгийг бэлэн гэж тооцохгүй.

Хуримтлалын өгөөж, инфляц, банкны шимтгэл, даатгал оруулаагүй тогтмол хүүгийн
төлөвлөлтийн тооцоо. Банкны батлагдсан санал биш. Нэмэлт эх үүсвэрийн биелэлт,
зээл олголт болон хөрөнгө худалдаж авах эцсийн нэг удаагийн мөнгөн урсгалыг
автоматаар банкны гүйлгээ болгож үүсгэхгүй. Сарын төсөвт хуримтлал ба зээлийн төлбөр холбогдоно.
Зорилгын нөхцөл засахад өмнөх саруудын төлөвлөгөө ч шинэчлэгдэнэ; хувилбарын түүх хадгалахгүй.
Бодит гүйцэтгэлийг оруулсан ч төлөвлөсөн хуваарь өөрөө дахин тохируулагдахгүй.
